## §8 — Frontier Partner Specialization

**Target:** End FY27 (June 2027)  
**Prerequisites:** AI Platform Specialization (§6) OR Data Security/IAM Specialization (§7).

### Audit Requirements

The Frontier Partner Specialization requires a capability audit. Based on Section 3.4 and EC101/EC102 deck references:

| Audit area | Evidence required | Hub implementation |
|---|---|---|
| **Agentic deployment at scale** | ≥ 5 production agent deployments with telemetry | Agent Control Tower panel + Foundry Telemetry |
| **Tamper-evident audit trail** | Signed, exportable audit log | `AuditExporter` (Phase 2 roadmap) |
| **Responsible AI** | RAI Playbook with evidence per pillar | RAI Playbook (Phase 4 roadmap) |
| **Agent governance** | Kill-switch + RBAC + versioning | Phases 1–2 roadmap |
| **Customer telemetry** | 30%+ workforce "agentic" (Fusion5 benchmark) | `TelemetryService` → Azure Monitor |
| **Frontier Engineer staff** | 5 staff with Frontier Engineer Badge | Skilling roadmap below |
| **Marketplace listings** | ≥ 3 live listings | Listing portfolio above |
| **Security compliance** | Security Specialization (Data Security or IAM) | §7 |

### AgentCraftworks-Hub's Role in the Frontier Partner Audit

Hub is the **evidence engine** for the Frontier Partner audit:
- `AuditExporter` generates the tamper-evident audit package
- `TelemetryService` feeds Azure Monitor with agentic adoption metrics
- `AgentVersionStore` provides deployment history
- `RaiPlaybookStatus` MCP tool provides RAI pillar scores
- `AgentControlTowerPanel` screenshots serve as visual evidence of agent governance
